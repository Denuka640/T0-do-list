# TaskFlow — To-Do List Application

> **Note:** This is a small university project and not one of my main/passionate builds. Please keep that in mind when viewing this repository!

---

## 📌 About The Project

A lightweight, modern client-side To-Do List application built using HTML, CSS, and Vanilla JavaScript with support for plain-text file storage (`.txt`).

### Features
- 📁 **Text File Storage (`.txt`)**: Save and load tasks directly to/from `.txt` plain text files.
- 🎨 **Modern Interface**: Custom dark/light mode toggle, smooth styling, and progress tracking.
- ⚡ **Task Management**: Priority levels (P1 to P5), inline editing, drag-and-drop reordering, and search/filtering.
- 💾 **Automatic Local Persistence**: Automatic sync with browser LocalStorage.

---

## 🚀 How to Run

Simply open `index.html` in any web browser. No complex build tools or server setup required!
