## 📌 Project Overview

A combined single-page utility web application developed as part of a university web design workshop. Built with plain HTML, CSS, and Vanilla JavaScript with clean tab navigation for multiple modules.

### Included Modules & Features
1. 📝 **Tasks (To-Do List)**:
   - Plain text file storage (`.txt`) import & export.
   - Priority levels (P1 to P5) with visual badges.
   - LocalStorage auto-persistence.
   - Drag-and-drop reordering, inline editing, search, and filtering.

2. ⏱️ **Stopwatch** (Part 1 Worksheet):
   - Millisecond-precise timer (`00:00:00.000`).
   - Start, Stop, Lap split tracking, and Reset controls.

3. ⏳ **Countdown Timer** (Part 2 Worksheet):
   - Input custom countdown time in seconds.
   - Quick preset buttons (1 min, 5 min, 25 min Pomodoro).
   - Alert notification when countdown reaches zero.

4. ⏰ **Alarm Clock** (Part 3 Worksheet):
   - Real-time digital clock display (`HH:MM:SS`).
   - Set custom alarm time and clear alarm.
   - Audio/toast/alert notification when current time matches alarm.

5. 🗂️ **Multi-Tab Interface** (Part 4 & 5 Worksheet):
   - Seamless section hiding/displaying with tab navigation.
   - Light & Dark theme toggle.

Simply open `index.html` in any web browser. No external dependencies or build tools required!
